<p>Bank Management System:
<br>This project is a command-line Bank Management System implemented in C.
Its primary function is to manage basic banking operations using file I/O for persistent data storage.
It allows users to create new accounts, process deposits and withdrawals (including a check for insufficient funds), query account balances, update existing account details, and close accounts.
All account records are saved to a binary file named Bank_Account.dat, demonstrating essential C concepts like structures, functions, and binary file manipulation.<p>
